# Report font

`noto-sans-sc-report.ttf` is a 400-weight static glyph subset of
`NotoSansSC[wght].ttf` from the Noto Sans SC project. It contains ASCII,
common Simplified Chinese (GB2312), punctuation, and every additional glyph
used by the deterministic report templates. The PDF renderer loads it only
when a report is generated; it is not part of the main application bundle.

Source: <https://github.com/google/fonts/tree/main/ofl/notosanssc>
